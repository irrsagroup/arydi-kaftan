# ARYDI KAFTAN - Luxury Moroccan Kaftan E-commerce

## Description
ARYDI KAFTAN is a full-stack e-commerce website for luxury Moroccan kaftans, built with the MERN stack (MongoDB, Express.js, React, Node.js).

## Features
- Bilingual support (English / Arabic) with RTL
- Product catalog with categories (Kimono, Kaftan, One Piece, Two Piece, Djelaba, Jewelry)
- Shopping cart with localStorage
- User dashboard with order history
- Admin dashboard for product management
- Image upload (SVG, PNG, JPG, WebP) up to 8 images per product
- Appointment booking system
- Checkout and order confirmation
